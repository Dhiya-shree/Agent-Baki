# Project Write-Up: BAKI - SRE Automation Tool

## Project Overview

**Project Name:** BAKI - Intelligent SRE For Dev   
**Technology Stack:** Java Spring Boot, Thymeleaf, PostgreSQL, IBM Watsonx AI  
**Development Tool:** BOB (AI-Powered Development Assistant)  
**Project Type:** Developer SRE Automation Platform
**Target user:** Developer working between meetings , tasks and bug fix 

## Executive Summary

BAKI is an intelligent Site Reliability Engineering (SRE) automation tool designed to streamline incident management, automate responses, and integrate with enterprise systems like Jira, Outlook, and GitHub. The project was developed with significant assistance from BOB, an AI-powered development assistant that helped create comprehensive documentation, implement complex features, and maintain code quality throughout the development lifecycle.


#### Need:

Baki helps Developers to easily manage incidents and automate responses. It integrates with Jira, Outlook, and GitHub to streamline workflows and reduce manual intervention. The tool leverages AI to predict and resolve issues, ensuring faster incident resolution and improved system reliability. Baki is designed to be user-friendly, scalable, and adaptable to various enterprise environments.

Baki helps the developer between meeting , multiple tickets tasks and actual codeing .
